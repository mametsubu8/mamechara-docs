Q&A

気になるところを開いてください。多いのは位置のスライダーが効かない（ドラッグの上書きが残っている）と、クリックが下のUIに通る／通らない（クリック遮断範囲）の2つです。

位置のスライダーを動かしてもキャラが動かない

そのウィンドウでキャラをドラッグして動かした位置が残っているからです。配置のスライダーは初期位置（まだ動かしていないウィンドウの位置）を決めるもので、一度ドラッグしたウィンドウはそのウィンドウ専用の位置が優先されます。

戻し方は3つあります。

  • 簡単設定のウィンドウごとの位置をリセット（そのスロットの上書きを全部消す）
  • 配置タブのウィンドウごとの位置の一覧で、行ごとに消す
  • 全体タブの表示先一覧で、行の↺を押す（そのウィンドウの分だけ）

この仕組みはわざとこうなっています。同じキャラを「Scene では左上、Hierarchy では下端からはみ出させる」と使い分けられるようにするためです。

キャラが端で切れる／全部見えない

仕様です。位置は 0〜1 がウィンドウの内側で、範囲の外にも置けます。端から半分だけのぞかせる置き方ができるようになっています。

全部見せたいなら位置を内側に戻すか、スケールを小さくしてください。

設定したのにキャラがどこにも出ない

上から順に確認してください。

  1. 全体タブの MameChara を有効にするが切れていないか
  2. どのウィンドウに出すで、出したいウィンドウが表示しないになっていないか
  3. そのウィンドウに別のスロットが割り当てられていないか
  4. 選んだスロットにキャラ画像が入っているか（スロット番号の横の「●」が目印）
  5. 再生中なら Play中は隠すが入っていないか
  6. ウィンドウの外にドラッグして追い出していないか（上の「位置のスライダーが効かない」の戻し方でリセット）
吹き出しが出ない

吹き出しは画像もセリフも無いと出ません。どちらか片方があれば出ます。

  • 画像が無い場合、吹き出しのテキストが有効になっているか
  • セリフの欄が空になっていないか（1行にひとつ書きます）
  • 画像を使いたいなら同梱の画像から選ぶ...で既定の吹き出しを選べます
独り言（自動表示）が出てこない
  • クリックで吹き出しを開いているあいだは出ません。これは意図した動きです。記憶シェルフを触っているときに独り言で上書きされないようにしています。一度クリックして閉じてください。
  • 出す間隔が 0 になっていないか（0 で黙ります）
  • 独り言のセリフ欄が空になっていないか
  • イベント（コンパイル完了・Play開始・シーン保存）は、それぞれのチェックが入っていて、かつそのセリフが書かれている必要があります

セリフが重なったときの優先度はクリック→イベント→独り言です。クリックは割り込み、出ていた自動表示は打ち切られます。

キャラを押したのに下の Hierarchy や Project が反応する

クリック遮断範囲がキャラより小さいか、位置がずれています。クリックタブで範囲を赤枠で表示するを入れると、どこで受け止めているかが見えます。

キャラの見た目より少し大きいくらいが目安です。

キャラの近くのボタンが押せなくなった

逆にクリック遮断範囲が広すぎます。赤枠を出して、本来のUIにかぶっていないところまで狭めてください。

キャラを端に寄せてから範囲を決めると、ぶつかりにくくなります。

赤い枠が消えない

赤枠は設定ウィンドウを開いているあいだだけ表示されます。設定を閉じれば消えます。開いたまま消したい場合はクリックタブの範囲を赤枠で表示するを切ってください。

ウィンドウの背景を透明にしたい

Unity の現在の仕様上、ウィンドウ自体は透明にできません。

透過でウィンドウに置きたいときはどのウィンドウに出すを使ってください。 Scene / Hierarchy / Inspector / Project / Console / Game の上にキャラだけを直接描く方法で、背景は一切塗りません。

アニメが動かない／止まる
  • 2枚目（アニメ）の画像が設定されているか。1枚だけだと止まったままです
  • クリック差分を表示中はアニメが止まります（仕様）
  • 他のアプリを使っているあいだ動かないのは Unity が非アクティブのときアニメを止めるが入っているためです。見えないところで動かさないぶん軽くなります
プリセットを適用したら吹き出しや背景が変わった／変わらなかった

プリセットには「何を含むか」が記録されていて、含まれている部分だけが上書きされます。

  • 吹き出しが変わらなかった→そのプリセットは吹き出しを含んでいません
  • 自分の背景が消えた→そのプリセットは背景を含んでいます

自分で書き出すときは、キャラタブのプリセットとして保存で吹き出しを含める／背景を含めるを選べます。詳しくはプリセットを配るへ。

更新したら設定が消える？

消えません。設定・画像・プリセットはAssets/ではなくProjectSettings/MameChara/に保存されていて、.unitypackageのインポータはここに触りません。新しい.unitypackageを上からインポートしてください。

別のプロジェクトや別のマシンに移したい

全体タブの設定の持ち出しですべて書き出す...を押すと、4スロット分の設定・画像・表示先・全体オプションが .mamecharaset 1ファイルになります。移した先で読み込んで置き換える...。

読み込むと、その環境の設定は全部置き換わります。キャラ1体だけを渡したいときは.mamechara（プリセット）の方を使ってください。
